# SHAG Engineering — финальный пакет сайта

Это готовое к коммиту состояние проекта. Сборка проверена: `npm install && npm run build` проходит без ошибок, в `dist/` попадают все нужные файлы.

## Что внутри и что уже сделано

**public/configurator3d.html** — автономный 3D-конструктор дома (движок three.js вшит внутрь, внешних зависимостей ноль):
- вращение мышью и пальцем, зум колесом и **щипком двумя пальцами**;
- виды: Экстерьер / Планировка (крыша снимается, чертёж с зонами и площадями) / Интерьер (камера внутри, мебель);
- параметры: высота, угол крыши, толщина стен, этажность (2-й этаж — спальня с кроватью, перила, лестница);
- цвета: кровля, фасад, отделка внутри (пол и мебель, с сохранением текстуры досок), окна;
- кнопка **«⬇ Скачать .GLB»** — генерирует модель в текущей конфигурации пользователя, с запечёнными текстурами;
- управление с сайта через postMessage (`{type:'shag3d', params/colors/view/export}`), режим `?embed=1`;
- экранная самодиагностика: любая ошибка выводится текстом во вьюпорт.
Проверен автотестами (эмуляция кликов по всем контролам) и официальным валидатором Khronos glTF: 0 ошибок, 0 предупреждений.

**public/models/shag-aframe-house.glb** — отчуждаемая модель дома (2 этажа, мебель, участок), 462 КБ, валидна. Для отправки заказчику, презентаций, AR-вьюеров.

**public/hero.jpg, public/model-fallback.jpg** — оптимизированные изображения (вместо исходных 4K по 8 МБ).

**Удалено из public/:** три кириллических .jpeg (23 МБ) и `configurator3d copy.html` — мусора больше нет.

**src/** — текущий рабочий код сайта: hero-фон, конфигуратор с iframe-3D и синхронизацией панелей, SVG-планировки, планировщик с drag-and-drop, футер.

## Как задеплоить

Важно понимать: **коммит в GitHub сам по себе не обновляет опубликованный сайт** — сайт публикует кнопка Publish в Bolt. Поэтому два пути:

**Путь Б — чистый старт (рекомендую).**
1. Залей содержимое этого пакета в репозиторий GitHub (через веб: Add file → Upload files, перетащить всё; старые файлы public/ предварительно удалить).
2. В Bolt импортируй репозиторий заново: открой `bolt.new`, выбери Import from GitHub (публичный репозиторий открывается ссылкой вида `bolt.new/github.com/ВЛАДЕЛЕЦ/РЕПО`).
3. В новом проекте отправь один промпт «Мобильная адаптация» (ниже), дождись, проверь превью на ширине 390px.
4. Publish → в настройках публикации переподключи домен `shagenrealestate.com`.

**Путь А — остаться в текущем Bolt-проекте.**
GitHub становится источником правды и бэкапом, но файлы в живой проект доносятся как раньше: `configurator3d.html` — вложением к сообщению + Node-скрипт замены по маркеру `MOBILE_TOUCH_V6`; `models/shag-aframe-house.glb` в Bolt не нужен вовсе (кнопка в конструкторе генерирует модель сама). Затем промпт «Мобильная адаптация» и Publish.

## Проверка на телефоне после Publish

Открыть сайт в режиме инкогнито (чтобы кэш не подсунул старое): бургер открывается и блокирует прокрутку → hero целиком на экране, кнопки в столбик → конфигуратор одной колонкой → глобус: дом вращается пальцем, зумится щипком, кнопка «⬇ Скачать .GLB» на месте → планировщик: объекты ставятся тапом → в футере тап по телефону открывает звонилку. Прямая проверка конструктора: `shagenrealestate.com/configurator3d.html`.

## Если нужен арт-уровень 3D

Текущая модель — потолок того, что рисуется кодом (текстуры, гирлянда, полный интерьер, свет). Следующий уровень — фотореалистичный GLB с PBR-картами делает 3D-художник в Blender по вашему рендеру; техзадание для фрилансера можно составить по запросу. Готовая модель подключится в конструктор без переделки архитектуры.
